## Caveats

- One donor: no donor or study holdout; plate stands in for a covariate, on two drugs only.
- Tabular models (TabPFN, ridge, kNN) see 13 training drugs per held-out drug, one pseudobulk per target; repeated subsampled pseudobulks (replicates and extra context rows) are left for the full report. They never read the query cells, so query arms change only STACK.
- STACK: frozen Stack-Large-Aligned, T = 1. Prompts below 333 cells are repeated within STACK's window, so the prompt-size arm measures a small prompt repeated, not fewer prompt slots.
